## 🎯 Що це і навіщо

Більшість інвестиційних рішень приймається в емоційному стані: FOMO, страх упустити, бажання довести щось. Структурований аналіз допомагає це нейтралізувати.

**6 капелюхів** — це методика, де одна інвестиційна ідея послідовно розглядається з шести різних позицій:

| Капелюх | Роль |
|---|---|
| 🔵 **Синій** | Фасилітатор — структурує процес, ставить уточнювальні питання, синтезує висновки |
| ⚪ **Білий** | Аналітик фактів — числа, фундаменти, ринкові дані, податковий розрахунок |
| 🔴 **Червоний** | Інтуїція та емоції — виявляє FOMO, anchoring, identity investing |
| ⚫ **Чорний** | Критик і ризик-менеджер — системно перебирає категорії ризиків |
| 🟡 **Жовтий** | Оптиміст з обґрунтуванням — реальні переваги, не "круто", а "круто тому що X" |
| 🟢 **Зелений** | Креатив і альтернативи — розширює простір рішень за межі бінарного "купувати чи ні" |

Скіл доповнює класичну методологію специфічними правилами для **українського інвестора**: розрахунок податку через курс НБУ, перевага UCITS Accumulating ETF, аналіз "примарного" гривневого доходу при девальвації, інтеграція з ринковими даними через EODHD MCP.

## 👥 Кому корисний

Скіл буде корисний, якщо ви:

- **Український інвестор** з рахунком в Interactive Brokers або плануєте відкрити
- **Самостійно** приймаєте інвестиційні рішення (не делегуєте порадникам)
- Розглядаєте інструменти з валютою купівлі **USD/EUR** і хочете правильно рахувати **гривневий** податковий результат
- Маєте портфель від **$10K** і вище, де якісний аналіз перед угодою має сенс
- Цінуєте **дисципліну** над імпульсивністю — хочете рамку, яка змусить подумати з різних кутів
- Аналізуєте акції, ETF, облігації США або UCITS, а можливо й венчурні інвестиції

**Скіл НЕ підійде, якщо ви:**
- Шукаєте конкретні поради "купуй X зараз" — скіл дає рамку для думання, не рекомендації
- Активний день-трейдер з горизонтом години-дні (методологія для рішень з горизонтом тижні+)
- Інвестуєте виключно в український ринок без валютних позицій (тоді не потрібен податковий блок з курсом НБУ)

## ⚙️ Як це працює

Коли ви викликаєте скіл явною фразою (наприклад, *"застосуй 6 капелюхів"*), Claude:

1. **Питає підтвердження** перед запуском (щоб не розгортати методологію випадково)
2. **Класифікує тип тези** — directional bet, income play, long-term hold, hedge, tactical, venture
3. **Збирає факти** через EODHD MCP (ціни, фундаменти, yields) і web search (макро, курс НБУ)
4. **Послідовно проходить капелюхи** з адаптацією до типу тези
5. **Видає синтез** з конкретною рекомендацією: розмір позиції, інструмент, поетапний вхід, exit-тригери

Приклад повного прогону можна побачити у файлах `examples/example-bond-thesis.md` і `examples/example-equity-thesis.md`.

## 🚀 Налаштування — крок за кроком

### Крок 1: Реєстрація на EODHD (джерело ринкових даних)

EODHD — це провайдер фінансових даних. Скіл використовує його **MCP сервер** для отримання цін, фундаментів, yields. Без EODHD скіл працює, але Білому капелюху доводиться все шукати через web search, що менш точно і повільніше.

1. Перейдіть на [eodhd.com](https://eodhd.com/register)
2. Зареєструйтесь (можна через Google або email)
3. Підтвердіть email
4. Free план дає **20 API запитів на день** — це 3-5 повних аналізів. Якщо плануєте інтенсивно використовувати — є платні плани від ~$20/міс зі значно вищими лімітами.

**Знайти свої лімити:** [eodhd.com/cp/dashboard](https://eodhd.com/cp/dashboard)

### Крок 2: Підключення EODHD як MCP конектора в Claude

1. Зайдіть на [claude.ai](https://claude.ai) і залогіньтесь
2. Натисніть на свій аватар у нижньому лівому куті → **Settings**
3. Перейдіть у вкладку **Connectors**
4. Натисніть **Add custom connector**
5. У полі URL вставте: `https://mcpv2.eodhd.dev/v2/mcp`
6. У полі Name вставте: `eodhd`
7. Натисніть **Add** і пройдіть OAuth (увійти своїм EODHD акаунтом)
8. Переконайтесь що конектор з'явився в списку зі статусом **Connected**

### Крок 3: Увімкнення Skills у Claude

1. У **Settings** → **Capabilities** (або **Features**)
2. Увімкніть тумблери:
   - **Code execution and file creation** (обов'язково для скілів)
   - **Skills** (обов'язково)
3. Збережіть зміни

### Крок 4: Завантаження скіла

1. Скачайте готовий ZIP: [⬇️ six-hats-investment-skill-only.zip](https://github.com/fintato/six-hats-investment/releases/latest/download/six-hats-investment-skill-only.zip)
2. У claude.ai → **Settings** → **Capabilities** → **Skills** → **Create skill**
3. Завантажте скачаний ZIP файл (розпаковувати не потрібно)
4. У списку Skills знайдіть `six-hats-investment` і ввімкніть тумблер

> 💡 **Для розробників:** альтернативно можна клонувати репозиторій через `git clone https://github.com/fintato/six-hats-investment.git`, але тоді треба самостійно запакувати папку у ZIP перед завантаженням у Claude.

### Крок 5: (Опціонально) Створення Project і portfolio.md

Для найкращого досвіду рекомендую:

1. У claude.ai створіть новий **Project** (наприклад, "Investments")
2. У **Project Knowledge** додайте файл `portfolio.md`, заповнений за шаблоном з `references/portfolio-template.md`
3. Тепер усі чати в цьому Project матимуть автоматичний доступ до вашого портфельного контексту

Без цього кроку скіл працює — він просто запитуватиме портфельні параметри щоразу.

### Крок 6: Перевірка

У будь-якому новому чаті (краще — у створеному Project) напишіть:

```
Розглядаю купити VOO на $10K на 5 років. Застосуй 6 капелюхів. 
```
або 
```
Хочу купити 10 акцій компанії ABCD тому що:
EPS вище прогнозу;
P/B <1.
Моя стратегія виходу з інвестиції:
фіксація 50% при зростанні на 40%;
фіксація 35% при зростанні на 70%;
фіксація 15% при зростанні на 150%.  
```

Claude має:
- ✅ Спитати підтвердження запуску скіла
- ✅ Після "так" — почати з Синього капелюха з уточнюваннями
- ✅ Викликати EODHD MCP для отримання даних (з'являться `tool calls`)
- ✅ Пройти всі 7 фаз методології
- ✅ Видати фінальну рекомендацію з exit-тригерами

## 💬 Як використовувати

### Тригерні фрази

Скіл активується **тільки** на явні фрази:
- `"застосуй 6 капелюхів"`
- `"проаналізуй методом 6 капелюхів"`
- `"повний аналіз через капелюхи"`
- `"розбери через 6 капелюхів"`
- `"шість капелюхів"`

Інші формулювання можуть не спрацювати — це навмисно, щоб не розгортати важку методологію випадково.

### Типові формати запитів

**Простий запит:**
```
Куплю SCHD на $5K як дивідендну стратегію на 10 років. Застосуй 6 капелюхів.
```

**Розширений (з контекстом):**
```
Думаю про short-позицію по TSLA через put-опціони. Розмір — $3K в премії, 
горизонт — до earnings через 6 тижнів. Мій VOO має ~2% TSLA через індекс. 
Застосуй 6 капелюхів.
```

**Запит на хедж:**
```
Як захистити мій VOO-портфель від AI-bubble crash? 
Готовий виділити 10% портфеля на хедж. Повний аналіз через капелюхи.
```

### Що очікувати на виході

Повний прогін займає **5-10 хвилин** і **3-8 запитів EODHD API**. Виходом є структурований аналіз:

1. **Класифікація тези** (тип, переформулювання якщо неточне)
2. **Білий**: факти + сценарний UAH розрахунок (3 сценарії)
3. **Зелений**: 3-5 альтернатив, включно з SPOT vs Options vs Futures для directional ідей
4. **Жовтий**: обґрунтовані переваги
5. **Чорний**: ризики з mitigations
6. **Червоний**: емоційна діагностика з контр-тестами
7. **Синій фініш**: оцінка X/10, конкретна структура позиції, поетапний вхід, exit-тригери

## 📂 Структура скіла

```
six-hats-investment/
├── SKILL.md                          # Основний файл: YAML + методологія + 10 правил
├── references/                       # Референс-документи
│   ├── portfolio-template.md         # Шаблон portfolio.md
│   ├── thesis-classifier.md          # Деталі класифікації типів тез
│   ├── tax-ukraine.md                # Український податковий блок
│   └── exit-triggers.md              # Типові exit-тригери за класами активів
└── examples/                         # Референсні приклади
    ├── example-bond-thesis.md        # Повний аналіз: 30Y treasuries
    └── example-equity-thesis.md      # Короткий аналіз: NVDA
```

### Ключові правила скіла (всі 10 в SKILL.md)

1. **Tax Events Count** — рахувати кількість податкових подій на рік для кожного інструменту
2. **UCITS Priority** — UCITS Acc дефолтний для довгострокових позицій
3. **Portfolio Context** — жодна позиція не аналізується у вакуумі
4. **Implementation Paths** — для directional тез обов'язкове порівняння SPOT vs Options vs Futures
5. **Адаптивний горизонт** — замість фіксованого терміну → trigger-based exits
6. **Hedge Reframing Test** — чесно називати, чи це хедж чи прихована directional ставка
7. **UCITS Check** — для будь-якого dividend-yielding інструменту перевірити UCITS Acc альтернативу
8. **Combo over Pure** — Зелений капелюх розглядає combo-стратегії, не лише single-instrument
9. **Trigger-based Exits** — кожна рекомендація закінчується numerical exit-тригерами
10. **Stagflation Hedge** — для bond/rate тез обов'язково розглядати TIPS-overlay

## 🎨 Кастомізація під себе

Скіл написано як **набір markdown-файлів**, не як код. Це означає, що його легко адаптувати під свої потреби:

### Свій профіль інвестора
Якщо ви **не український** інвестор — замініть блок "Контекст за замовчуванням" у `SKILL.md` під свою юрисдикцію. Замініть `references/tax-ukraine.md` на податкові правила своєї країни.

### Свої правила
Можете додавати власні правила в розділ "10 правил аналізу" в `SKILL.md`. Наприклад, "Правило 11: для всіх венчурних інвестицій вимагати MOIC-projection мінімум 3x".

### Свої тригерні фрази
У YAML-заголовку `SKILL.md` змініть `description` — додайте чи приберіть тригерні фрази.

### Свій тон
У розділі "Тон і формат" можна налаштувати: більш формально / більш розмовно, з гумором / суворо, обережно / прямолінійно.

**Після правок:** перепакуйте папку в ZIP, видаліть стару версію скіла в Claude і завантажте нову.

## ⚠️ Обмеження

**Технічні:**
- Скіл працює **тільки на Claude Pro і вище** (Skills недоступні на Free)
- EODHD Free план дає 20 запитів/день — для інтенсивного використання потрібен платний план
- Claude інколи **імпровізує** і може об'єднати фази або змінити порядок капелюхів. Якщо це небажано — попросіть *"чітко по фазах, не об'єднуй"*.
- Скіл активується модель-driven (Claude сам вирішує). На дуже коротких фразах (типу просто `"6 капелюхів"`) може не спрацювати — використовуйте повніші тригери.

**Концептуальні:**
- Скіл — це **рамка для думання**, не порадник. Усі рішення приймає інвестор.
- Якість аналізу залежить від якості введених даних (тези, контексту, портфеля).
- Український податковий блок написаний за станом на **2026** і відображає ставки 18% ПДФО + 5% військовий збір. При зміні законодавства треба оновити `references/tax-ukraine.md`.
- Емоційна діагностика (Червоний капелюх) працює тим краще, чим більше контексту ви даєте про свої мотиви.
